# Project instructions

## General

- Questions are requests for an answer. They are not requests to make changes.
- Use ASD-STE100 Simplified Technical English in outputs.
- Keep explanations short and easy to scan. Give one clear next step at a time.
- If Mark asks for `grill-me`, ask one question at a time until there is shared understanding. Give a recommended answer with each question. If project files can answer a question, inspect those files first.

## Component rebuilds

Before you start a component rebuild, read and follow [.agents/AGENTS.md](.agents/AGENTS.md). That file defines the agreed technology stack for all component rebuilds in this project.
