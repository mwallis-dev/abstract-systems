# Icon review sources

8,258 icons copied from Aria Icons' vendored Lucide, Tabler, and Heroicons collections on 16 October 2026:
https://github.com/LeulAria/Aria-Icons/tree/main/apps/web/icons/vendored

The demo searches this local subset, not the full Aria catalogue. No hosted API is used.
Copied source IDs use `collection:original-svg-path` to identify artwork and variants unambiguously. They are source references, not API lookup IDs.

Original artwork and metadata are retained. Each collection's MIT license is included beside this file.

- Lucide: https://github.com/lucide-icons/lucide
- Tabler: https://github.com/tabler/tabler-icons
- Heroicons: https://github.com/tailwindlabs/heroicons

Run the existing development server and open `/icons.html`. Search by icon name, collection, style, or available tags. Click a card to copy its source ID. At most 240 matches are shown; refine the search to find others.
